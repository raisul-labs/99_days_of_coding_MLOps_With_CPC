# EDA Findings – Diamond Dataset

## Three Findings
1. Carat has a strong positive correlation with diamond price.
2. The x (length) feature also shows a positive correlation with price.
3. Diamond price generally increases as carat weight increases.

## Data Quality Issue
- Issue: Some numerical features may contain outliers.
- Solution: Checked numerical distributions using histograms and correlation analysis.

## Reflection
- What I built: I performed Exploratory Data Analysis (EDA) and correlation analysis on the Diamond Dataset.
- What broke: Some features had unusual values that needed further investigation.
