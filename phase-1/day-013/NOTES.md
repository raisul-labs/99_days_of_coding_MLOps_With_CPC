- Python
- Pandas & NumPy
- Matplotlib
- Seaborn

### Tasks
- Data Exploration
- Statistical Analysis
- Missing Value Checking
- Correlation Analysis
- Data Visualization (Heatmap, Histogram, Boxplot, Scatterplot, Regplot)

**Goal:** Understand data patterns, relationships, and correlations between numerical features.
